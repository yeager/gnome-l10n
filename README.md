# GNOME L10n

Translation statistics for GNOME modules.

## Install

### Ubuntu / Debian
```bash
sudo apt install gnome-l10n
```
Repo: [yeager/debian-repo](https://github.com/yeager/debian-repo)

### Fedora
```bash
sudo dnf install gnome-l10n
```
Repo: [yeager/rpm-repo](https://github.com/yeager/rpm-repo)
