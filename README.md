# GNOME L10n

GNOME translation statistics viewer with Vertimus links.

Built with GTK4/Adwaita. Part of the [Danne L10n Suite](https://github.com/yeager/debian-repo).

## Installation

### Debian/Ubuntu
```bash
sudo apt install gnome-l10n
```

### Fedora/RPM
```bash
sudo dnf install gnome-l10n
```
